# Terra AR

Projeto de realidade aumentada desenvolvido como laboratório de tecnologia.

## Objetivo

Explorar aplicações de realidade aumentada e desenvolvimento web, colocando em prática a integração entre tecnologia, programação e experiências interativas.

## Tecnologias

- HTML
- CSS
- JavaScript
- Recursos de realidade aumentada para web

## Ideia do projeto

O projeto faz parte dos experimentos que mantenho no GitHub para testar tecnologias e transformar ideias em protótipos funcionais.

**Status:** projeto experimental/em desenvolvimento.
